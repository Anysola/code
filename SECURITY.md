# Security

Report security issues in Anysola Code by email to contact@anysola.com. Please do not open a public issue for
them.

Include the Anysola Code version (`anysola --version`), your platform, and steps to reproduce.

Anysola Code does not sandbox the agent. The permission prompts help you see what the agent does before it runs
commands or writes files, but they are not a security boundary. Run it in a container or VM if you need
isolation.

Issues in OpenCode code that are not specific to this fork can also be reported to the
[OpenCode project](https://github.com/anomalyco/opencode/security/advisories/new).
